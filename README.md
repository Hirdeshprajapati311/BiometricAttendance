# Biometric Attendance Management System

A full-stack attendance management system built with React, Node.js, Express, and MongoDB for managing employee attendance, leave requests, work schedules, and administrative operations.

## Features

### Authentication

- JWT Authentication
- Role Based Access Control
- Protected Routes

### Attendance

- Employee Check-In / Check-Out
- Late Arrival Detection
- Early Departure Detection
- Attendance History
- Attendance Reports

### Leave Management

- Apply Leave
- Leave Approval / Rejection
- Leave Status Tracking
- Leave Expiry Handling

### Employee Management

- CRUD Employees
- Department Management

### Work Schedule

- Request Schedule Changes
- Admin Approval

### Dashboard

- Attendance Analytics
- Employee Overview
- Graphs
- Summary Cards

---

## Tech Stack

### Frontend

- React, NEXT JS
- Vite
- Tailwind CSS
- TanStack Query
- Axios
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

## Installation

### Clone Repository

```bash

```

### Backend

```bash

npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
